## Sobre o projeto

O site reúne uma apresentação da série, atalhos para os canais oficiais, vídeo de fundo e um modal para assistir ao trailer. A interface foi ajustada para funcionar em computadores, tablets e celulares.

## Como funciona

- Layout responsivo sem texto espremido ou rolagem horizontal.
- Vídeo de fundo em telas maiores.
- Links externos protegidos com `noopener noreferrer`.
- Modal de trailer acessível por mouse e teclado.
- Fechamento pelo botão, pela tecla `Esc` ou pela área externa.
- Imagens com textos alternativos e foco de teclado visível.

## Tecnologias

- HTML5 para a estrutura.
- CSS3 para identidade visual e responsividade.
- JavaScript para controle do trailer.
